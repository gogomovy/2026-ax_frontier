### 화면에서 달라진 점
- **보고서**
  - "보고서로 내려받기"가 형식 메뉴(PDF · 한글 HWPX · 한글 HWP · HTML)로 바뀌었습니다.
  - "분석 다시 실행" 버튼을 누르면 단계별 진행이 실시간으로 보이고, 끝나면 화면이 새로 고쳐집니다.
- **근거**
  - "원본 열기"로 원본 문서 뷰어가 열리고, 인용된 면 · 인용문이 표시됩니다.
  - 근거는 공식성 · 시점 · 의미 · 개념 연결로 순위를 매기고, 외부 정책 · 내부 경영방향을 각각 1건 이상 보여줍니다.
  - 부서한정 문서는 소유 부서 사용자에게만 보입니다.
- **경영목표 설정**
  - 추천 범위 · 문구 · 산출 근거는 계산 커널이 만듭니다.
  - 상한을 넘는 값을 넣으면 경고가 뜨고, 사유를 적어야 확정됩니다.
  - 목표 시트에서 변경 이력(처리자 · 사유)과 변경 영향(다시 계산될 지표 · 화면 · 재검토할 방안)을 봅니다.
- **수행방안**: 가이드를 규칙 조건으로 고르고 판정 근거를 표시합니다(예: 충당금 비중 증가 1.19%p > 0 → 소매 풀 집중 모니터링).
- **AI Attention**: 순위 점수와 근거를 규칙 · 지표로 계산합니다(예: 기업여신 92.4점).
- **로그인**: SSO 를 설정하면 SSO 버튼이 생깁니다.
- **관리자**
  - 새 화면: [요청 추적] · [골든셋 평가] · [운영 알림 · 비용].
  - 데이터셋 업로드는 원본 보고서 양식을 자동 인식합니다.

## 4. 실행 · 검증

```bash
make up      # 6개 서비스 기동 (web · api · worker · postgres · neo4j · litellm)
make e2e     # 브라우저 시나리오 59개
make test    # 백엔드 테스트 112개
make eval    # 골든셋 평가 (결과를 관리자 [골든셋 평가]에 게시)
make perf    # 주요 API p50 · p95 · 기준치 대조
```

**CI(GitHub Actions) 세 잡**
- backend: 계층 의존 규칙(import-linter) · pytest(골든셋 포함) · 계산 커널 커버리지 90% 게이트.
- frontend: 타입 검사 · 린트 · 빌드 2종 · 의존성 보안 점검.
- e2e: Docker Compose 전체 기동 → 브라우저 시나리오 → 골든셋 → 성능 참고 측정(실패해도 빌드는 막지 않음).

**보안 테스트(`tests/test_security.py` · `tests/test_filecheck.py`)가 확인하는 것**
- SSO 거부 9종.
- 프롬프트 인젝션.
- 다른 부서 · 관리자 API 접근, 경로 조작, 세션 위조.
- 위장 · 매크로 · 압축 폭탄 · PDF 스크립트 · DRM 업로드.

**성능 기록**: `docs/성능기준치_2026-10-10.md` — 전 시나리오 기준치 안. 측정 중 발견한 한글 변환 동시 요청 오류는 고쳤습니다.
